# 🧴 Skincare E-Commerce Sales Analysis Using SQL

### 📊 A SQL-Based Business Analysis Project | Customer Insights | Sales Performance | Product Analytics

---

## 📌 Project Overview

This project focuses on analyzing a skincare e-commerce business using SQL to understand customer purchasing behavior, sales performance, product performance, returns, and customer satisfaction.

Using SQL, I analyzed data across six relational tables and worked on 40 business-focused SQL queries to uncover meaningful insights and answer real-world business questions.

The project demonstrates practical SQL skills, including data exploration, data analysis, joins, aggregations, subqueries, and advanced window functions.

## 🎯 Project Objectives

- Analyze overall sales performance and revenue trends.
- Identify top revenue-generating and repeat customers.
- Understand customer purchasing behavior.
- Evaluate product and category performance.
- Analyze returns and refund patterns.
- Identify low-rated products using customer reviews.
- Calculate Customer Lifetime Value (CLV).
- Perform data quality checks.

## 🗂️ Dataset Overview

The project uses six relational tables containing information about customers, orders, products, returns, and reviews.

| Table | Description |
|---|---|
| Customers | Customer details and acquisition channels |
| Orders | Order dates, payment methods, status and revenue |
| Order_Items | Product quantities and item-level sales |
| Products | Product names, categories, pricing and stock |
| Returns | Return reasons and refund status |
| Reviews | Customer ratings and product feedback |

**Dataset Files:** CSV and Excel formats.
